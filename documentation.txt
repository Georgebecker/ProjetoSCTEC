3. ESTRUTURA E ARQUIVOS IMPORTANTES
==========================================
- index.html — página principal (frontend)
- styles.css — estilos
- scriptcall.js — lógica do chatbot
- backend.js — servidor Express para salvar leads e fornecer chat (opcional)
- leads.json / leads.csv — armazenamento de leads gerados pelo backend
- services.csv — tabela editável de serviços e preços (formato CSV simples)

==========================================
4. FORMATO DO services.csv
==========================================
O arquivo `services.csv` tem duas colunas com cabeçalho:

service,price
"Banho & Tosa",120
Consultas,180
"Hotel para pets",150

Observações:
- `service`: nome do serviço (string). Use aspas se conter vírgula ou `&`.
- `price`: preço numérico (sem símbolo `R$`). O frontend converte para BRL ao exibir.

Para alterar preços ou adicionar serviços, edite [ProjetoSCTEC/services.csv](ProjetoSCTEC/services.csv) e atualize a página no navegador.

==========================================
5. COMO FUNCIONA O FORMULÁRIO
==========================================
- Os serviços são carregados do CSV pelo frontend e renderizados como checkboxes.
- O usuário pode marcar mais de um serviço; o sistema soma os preços e atualiza o campo `Valor total` automaticamente.
- No envio, o backend recebe um objeto JSON contendo: `nome`, `email`, `whatsapp`, `descricao`, `nomePet`, `raca`, `tipoServico` (string com lista de serviços), `valorServico` (valor numérico total) e `dataRegistro`.

==========================================
6. ROTEIRO DE TESTE (LOCAL)
==========================================
1) Iniciar o backend (opcional, para salvar leads):
```powershell
cd ProjetoSCTEC
node backend.js
```

2) Servir os arquivos estáticos (recomendado para evitar problemas de fetch do CSV):
```powershell
# Instale http-server se necessário: npm install -g http-server
cd ProjetoSCTEC
http-server -c-1
```
Ou use a extensão Live Server do VS Code e abra `index.html`.

3) Acesse a página no navegador, selecione serviços e submeta o formulário.
4) Verifique:
- Mensagem de sucesso exibida no formulário
- `leads.json` e `leads.csv` atualizados (se o backend estiver rodando)
- Console do navegador para logs e possíveis erros

==========================================
7. OBSERVAÇÕES TÉCNICAS
==========================================
- O frontend faz um fetch de `services.csv` via requisição HTTP; servir os arquivos por um servidor local evita problemas de CORS/file://.
- Se desejar, é possível mover a leitura do CSV para o backend e expor uma rota `/services` que retorne JSON.
- O campo `valorServico` enviado ao backend é numérico (string contendo número) — o backend atualmente grava tal valor em `leads.json` e no CSV de leads.
